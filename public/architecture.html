🔍 /api/chat — RAG Pipeline  ·  each step streams two events: running → complete
STEP 1
Analyze
Reads query + collection schema. Outputs structured plan: target collection, search mode, intent, limit, sort field.
ibm/granite-3-8b-instruct

Embed
Generates a query vector when the target collection is not using server-side vectorize.
Resolved AI backend · Hugging Face or local Ollama
STEP 3
Search
Queries Astra DB using the chosen mode: $vector, $vectorize, $hybrid, or lexical sort.
Astra DB — Data API
STEP 4
Respond
Synthesizes a natural language answer grounded in the retrieved documents.

☁️ External Services
Astra DB — DataStax Data API
Schemaless document store with first-class vector support. Supports client-side vectors ($vector), server-side vectorization ($vectorize), hybrid, and lexical search.
astra-db-ts SDK
Hugging Face
Primary hosted AI backend when a key is available. Provides Granite chat and embedding models for analyze, title generation, embeddings, and final response generation.
router.huggingface.co
Local Ollama
Automatic fallback when no Hugging Face key is available. Can pull missing Granite chat or embedding models on demand and exposes progress through the optional prepare step.
local HTTP API

💬 Local Persistence — SQLite Tables new
conversations
id string primary key
name string user-editable display name
created_at string ISO timestamp
updated_at string updated on every new message
message_count number denormalized for sidebar display
messages
id string primary key
conversation_id string → conversations.id
role string "user" | "assistant"
content string message text
timestamp string ISO — sort key for ordering
search_mode string optional · assistant only
pipeline_steps JSON text optional · full trace payload
sources JSON text optional · retrieved docs
ingested_documents
source_doc_id string primary key
source_filename string display name in the document library
collection string Astra collection that received the chunks
chunk_total number number of inserted chunk records
The local database file stores conversations, messages, and ingested document summaries independently from Astra collections. Astra continues to hold user collections and chunked document content.
