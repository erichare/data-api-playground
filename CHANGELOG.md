# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0] - 2026-04-13

### Added

- Interactive web UI for exploring DataStax Astra DB collections
- RAG chat with vector, hybrid, and lexical search modes
- Document ingestion with chunking (PDF, DOCX, CSV, XLSX, JSON, TXT, MD)
- Collection management (create, browse, delete)
- Conversation persistence with SQLite
- AI-powered conversation title generation
- Streaming responses for chat and ingestion
- Data API proxy with TypeScript client call logging
- Optional password authentication with HMAC-SHA256 sessions
- Security headers (CSP, HSTS, X-Frame-Options, Permissions-Policy)
- Embedding provider discovery
- Keyspace management
- MIT license and community documentation (CONTRIBUTING.md, SECURITY.md)
